## 🌟 Описание / Overview

**Circle** — это круговое меню-лаунчер для операционной системы Windows. Он предоставляет мгновенный доступ к вашим любимым программам, ярлыкам и веб-сайтам прямо под курсором мыши по нажатию горячей клавиши (по умолчанию `Alt + C`).

---

## 🚀 Основные возможности / Key Features

* **🎨 Разные стили оформления (Visual Styles)**:
  * **Fluent** — современный стиль Windows 11 с плавными градиентами и эффектом подсветки.
  * **Classic** — классические раздельные лепестки.
  * **Solid** — сплошное непрерывное монолитное кольцо.

* **⌨ Прямой вызов приложений по клавишам (Per-App Hotkeys)**:
  * Назначайте быстрые клавиши (`1`, `D`, `F1` и др.) к любым приложениям и сайтам.
  * Достаточно вызвать круговое меню (`Alt + C`) и нажать клавишу на клавиатуре — приложение **запустится мгновенно**!

* **🌐 Поддержка веб-сайтов и иконок (Favicon Auto-Fetching)**:
  * Добавляйте ссылки на сайты прямо в меню. Circle автоматически закрузит высокое разрешение фавиконки сайта.

* **🌍 Многоязычность (i18n)**:
  * Встроенная поддержка русского (`ru`) и английского (`en`) языков. Выбор языка в один клик.

* **📐 Гибкие размеры и анимации**:
  * Настройка внутреннего и внешнего радиуса кругового меню через слайдеры.
  * Анимации появления: **Expand** (расширение) и **Fade** (плавное проявление).

* **⚙ Импорт и Экспорт конфигурации**:
  * Сохраняйте и переносите список приложений и настроек в формате JSON.

## 🛠️ Установка и Запуск / Installation & Usage

### 1. Клонирование репозитория
```bash
git clone https://github.com/Paloxa/Circle.git
cd Circle
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск приложения
```bash
python circle.py
```

---

## ⌨ Горячие клавиши управления / Global Shortcuts

* `Alt + C` — Открыть / Скрыть круговое меню (настраивается в параметрах).
* `Esc` — Быстро закрыть открытое меню.
* `Правый клик по секторам` — Контекстное меню управления приложением (перемещение вверх/вниз, удаление, настройки).

## 📁 Структура проекта / Project Structure

```
Circle/
├── circle.py             # Главная точка входа и виджет кругового меню
├── settings_gui.py       # Окно настроек приложения (PyQt6 GUI)
├── utils.py              # Вспомогательные функции (Favicon, Иконки, Ярлыки)
├── i18n.py               # Система локализации (Интернационализация)
├── circle.png            # Логотип приложения
├── Config/               # Конфигурационные файлы пользователей
│   ├── apps.json         # Список прикреплённых приложений
│   └── settings.json     # Системные настройки
├── locales/              # Языковые пакеты
│   ├── ru.json           # Русский перевод
│   └── en.json           # Английский перевод
└── styles/               # Стили визуального оформления
    ├── base_style.py     # Базовый абстрактный класс стиля
    ├── fluent.py         # Стиль Fluent UI (Windows 11)
    ├── classic.py        # Стиль Classic
    └── solid.py          # Стиль Solid
```
