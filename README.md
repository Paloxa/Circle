# Circle — Radial App Launcher for Windows 11

Circle — это легкое и стильное круговое (радиальное) меню быстрого запуска приложений для Windows 11, вдохновленное концепцией Launchy для macOS.

Появляется мгновенно ровно вокруг вашего курсора по нажатию горячей клавиши, позволяя запускать любимые программы и утилиты за долю секунды.

## Особенности

* Мгновенный доступ: Вызывается комбинацией клавиш (по умолчанию Alt + C) прямо под курсором мыши.
* Дизайн Windows 11: Полупрозрачные элементы, мягкая подсветка, динамические зазоры между секторами и плавные анимации появления.
* Автоматические иконки: Автоматически подтягивает и отображает настоящие иконки приложений прямо из .exe файлов.
* Удобное окно настроек: Встроенный GUI для добавления новых программ через кнопку Обзор... и смены комбинации клавиш без редактирования кода.
* Работа в трее: Удобная иконка в системном трее Windows для быстрого перехода к настройкам или закрытия приложения.
* Не требует прав администратора: Работает из-под обычного пользователя без всплывающих окон UAC.

## Установка и запуск

### Вариант 1. Запуск готового .exe (Для пользователей)

1. Скачайте последнюю версию приложения из раздела Releases.
2. Распакуйте архив в удобную папку.
3. Запустите circle.exe.
4. Нажмите Alt + C на клавиатуре.

Чтобы Circle запускался автоматически при включении компьютера, нажмите Win + R, введите shell:startup и перетащите туда ярлык файла circle.exe.

### Вариант 2. Запуск из исходного кода (Для разработчиков)

1. Клонируйте репозиторий:
git clone [https://github.com/ВАШ_НИК/Circle.git](https://www.google.com/search?q=https://github.com/%D0%92%D0%90%D0%A8_%D0%9D%D0%98%D0%9A/Circle.git)
cd Circle
2. Установите необходимые зависимости:
pip install PyQt6 pynput
3. Запустите проект:
python circle.py
4. Сборка собственного .exe файла при необходимости:
pip install pyinstaller
python -m PyInstaller --noconsole --onefile circle.py

## Настройки

Вы можете открыть окно настроек через клик правой кнопкой мыши по синей иконке Circle в трее Windows (возле часов).

* Смена горячей клавиши: Введите нужное сочетание (например, alt+space или alt+c) в поле настроек и нажмите Сохранить.
* Добавление программ: Нажмите Обзор..., выберите нужный .exe файл, укажите понятное имя и нажмите Добавить приложение.

Все настройки и список приложений сохраняются в локальную папку Config (apps.json и settings.json).
